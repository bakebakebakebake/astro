# Rapide 主题语法完整指南

本文档详细介绍 Rapide 主题的所有语法特性，**重点关注代码块和标注（Asides）的处理**。

:::tip[快速提示]
Rapide 是 Starlight 的一个主题插件，它在 Starlight 的基础上提供了更现代、更优雅的视觉样式。所有 Starlight 的功能在 Rapide 中都可以使用。
:::

## 📌 一、标注（Asides）详解

标注（Asides）是用于突出显示特定信息的特殊块，在 Rapide 主题中样式优美，非常适合强调重要内容。

### 1.1 基本语法

标注使用三个冒号 `:::` 包裹，后面跟标注类型：

```md
:::note
这是一个普通提示。
:::
```

### 1.2 所有标注类型

Rapide 支持以下 5 种标注类型：

#### 📘 Note（笔记/提示）

用于一般性的提示信息。

**语法：**
```md
:::note
这是一个普通的提示信息，用于补充说明。
:::
```

**效果：**
:::note
这是一个普通的提示信息，用于补充说明。
:::

---

#### 💡 Tip（技巧/建议）

用于提供有用的技巧或最佳实践。

**语法：**
```md
:::tip
这是一个技巧提示，建议你这样做会更好！
:::
```

**效果：**
:::tip
这是一个技巧提示，建议你这样做会更好！
:::

---

#### ⚠️ Caution（警告/注意）

用于提醒用户需要注意的事项。

**语法：**
```md
:::caution
这是一个警告信息，请特别注意这个操作！
:::
```

**效果：**
:::caution
这是一个警告信息，请特别注意这个操作！
:::

---

#### 🚨 Danger（危险）

用于严重警告，表示可能导致严重后果的操作。

**语法：**
```md
:::danger
这是一个危险警告！此操作可能导致数据丢失或系统崩溃！
:::
```

**效果：**
:::danger
这是一个危险警告！此操作可能导致数据丢失或系统崩溃！
:::

---

### 1.3 自定义标注标题

你可以为标注添加自定义标题，使用方括号 `[]` 语法：

**语法：**
```md
:::note[💡 重要提示]
使用自定义标题可以让标注更加醒目和个性化。
:::
```

**效果：**
:::note[💡 重要提示]
使用自定义标题可以让标注更加醒目和个性化。
:::

**更多示例：**

:::tip[🎯 最佳实践]
在生产环境中，始终记得备份数据！
:::

:::caution[⚡ 性能警告]
此操作可能需要较长时间，请耐心等待。
:::

:::danger[🔥 严重警告]
执行此命令将永久删除所有数据，无法恢复！
:::

### 1.4 标注中的富文本

标注内部可以使用所有 Markdown 语法：

:::note[📝 功能丰富的标注]
标注内部支持：

- **加粗文本**
- *斜体文本*
- `行内代码`
- [链接](https://example.com)
- 列表项

甚至可以包含代码块：

```javascript
const message = "标注中的代码";
console.log(message);
```

和公式：$E = mc^2$
:::

3. **组织内容结构** - 使用标题、列表、卡片等组织内容层次
4. **保持一致性** - 在整个文档中保持风格统一
5. **及时更新** - 定期更新文档内容，保持准确性
:::

:::caution[⚠️ 注意事项]
- MDX 文件中的 import 语句必须在 frontmatter 之后
- 代码块的语言标识要正确，否则无法高亮
- 标注不能嵌套使用
- 组件必须先导入才能使用
:::
