## 步骤组件测试

<Steps>
  1. **安装依赖**
     
     使用你喜欢的包管理器安装依赖。
     
     ```bash
     npm install @astrojs/starlight starlight-theme-rapide
     ```
  
  2. **配置Astro**
     
     在`astro.config.mjs`文件中添加Starlight集成和Rapide主题。
  
  3. **创建内容**
     
     在`src/content/docs/`目录下创建Markdown或MDX文件。
  
  4. **启动开发服务器**
     
     ```bash
     npm run dev
     ```
</Steps>
